# Rove — Copywriting Skeleton

> **How to use this document**
> This document maps every piece of copy needed across the Rove website. Each section includes the **copy type**, **character guidance**, **tone notes**, and a **placeholder example** to illustrate intent. Replace all placeholder copy (shown in *italics*) with your final copy before handoff to development.
>
> **Copy Types at a glance:**
> - **H1** — Primary page headline. One per page. Bold, punchy.
> - **H2** — Section headline. Sets context for a content block.
> - **Body** — Paragraph or descriptive copy. Can be 1–4 sentences.
> - **Label** — Short UI text: nav items, tags, categories, captions.
> - **CTA** — Call-to-action button or link text. Short, active, directive.
> - **Micro** — Tiny UI copy: form placeholders, error states, hints.
