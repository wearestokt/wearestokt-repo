# Expert Copywriting

Produce copy that matches top-tier professionals: strategic, on-brand, psychologically grounded, and free of generic AI language. Documents you receive (brand guidelines, product specs, examples) are the source of truth—extract and apply them rigorously.

## When This Skill Applies

- User attaches or references documents (PDF, doc, markdown, Notion) containing brand voice, product info, or examples
- User asks for copy: landing pages, sales pages, ads, headlines, CTAs, web content, email sequences
- User wants output that is "on brand," "professional," "expert-level," or "thought through"

## Core Workflow

### 1. Ingest and Extract

Before writing anything:

- **Read all provided documents**—brand guidelines, tone of voice, product specs, competitor examples, style guides
- **Extract and list**:
  - Brand voice attributes (formal/casual, playful/serious, jargon level)
  - Target audience (who, pain points, desires)
  - Key differentiators and proof points
  - Forbidden words and preferred alternatives
  - Example phrases or passages to emulate
- **Confirm understanding** briefly: "I'm working with [audience], [tone], [differentiators]. Ready to write."

### 2. Choose Framework

Match the deliverable to a framework. See [reference.md](reference.md) for full definitions.

| Deliverable | Framework |
|-------------|-----------|
| Short ads, social, email subject lines | PAS (Problem → Agitate → Solution) |
| Sales pages, long-form | AIDA (Attention → Interest → Desire → Action) |
| Social, before/after stories | BAB (Before → After → Bridge) |
| Product descriptions | FAB (Features → Advantages → Benefits) |
| B2B, thought leadership | SCQA (Situation → Complication → Question → Answer) |
| Brand positioning, messaging | StoryBrand |

### 3. Write Section by Section

Do not dump a full page. Work in order:

1. **Headline** — One clear promise or outcome. Test 3–5 options.
2. **Subheadline** — Expand the promise, add specificity.
3. **Opening** — Hook that speaks to the reader's situation or pain.
4. **Body** — Follow the chosen framework. One idea per paragraph.
5. **Objections** — Address 1–3 real objections with proof.
6. **CTA** — Single, specific action. Benefit-focused, not feature-focused.

After each section, check against brand voice and anti-patterns before moving on.

### 4. Self-Edit for Quality

Before delivering, run this pass:

- [ ] **AI-ism check**: Search for banned phrases (see reference). Replace with concrete, specific language.
- [ ] **Clarity**: Could a smart 14-year-old follow the logic? Cut jargon unless the audience expects it.
- [ ] **Proof**: Are claims backed by data, testimonials, or specifics from the source docs?
- [ ] **CTA**: Is the next step obvious and compelling?

### 5. Deliver with Context

Output format:

```markdown
## [Deliverable Type]: [Working Title]

**Framework used:** [e.g., AIDA]
**Audience:** [brief]
**Tone:** [from brand docs]

---

[Copy here]

---

**Notes:** [Any assumptions, suggested A/B tests, or follow-up ideas]
```

## Quality Standards

**Expert-level copy:**

- Speaks to the reader's world first, product second
- Uses concrete benefits over abstract features
- Addresses real objections with proof
- Maintains one clear thread from hook to CTA
- Sounds human and on-brand, not generic or templated

**Never:**

- Start with "In today's fast-paced world..." or similar openers
- Use weasel words: "leverage," "transform," "comprehensive," "robust," "seamless," "cutting-edge," "innovative" (unless in brand docs)
- Bury the CTA or offer multiple competing CTAs
- Make claims without support from the source documents

## If Documents Are Missing

If the user wants copy but hasn't provided brand/product docs:

1. Ask for: tone of voice (3–5 adjectives), target audience, 2–3 differentiators, 1–2 example URLs or passages they admire
2. Proceed with explicit assumptions: "Assuming [X], here's the copy. Adjust if your tone is more [Y]."
